FlexyFooter


In this coding assignment, my section, header, nav became a flex container. For me it made it so the header, nav, and logo were in line with each other and it also let me be able to change the background color of just the header. I created the three column layout by making my section a flex container with each article being inside of it, making it a flex item. By doing this, it created three columns. The percentage width affected the columns by making each article skinnier or wider, condensing or distancing the words in each body. Changing the margins changed how far away they were from each other. I made the images consistent by using object-fit: contain, and changing the width and heigh to get them to be the same size. I had to troubleshoot many things like how to make the images even, how to space out the nav bar dynamically, and experiment with different margins to make the page look like the sample. When I resize the browser window at first, there would be parts that cut off, like the nav bar. But I was able to fix it so now the page resizes depending on the size of the window. I think FlexBox is definitely still confusing in general because there's many elements to it that I need to remember or know how to work. I could use FlexBox to create even columns in my inspiration page.
