For this assignment, I tried to copy the design of a website using my own HTML and CSS. I started by looking at how the website was organized and tried to recreate the layout with the text, images, borders, and different sections. A lot of the process was trial and error. Sometimes I would change something in the CSS and it would fix one part but make another part look wrong. One of the hardest parts for me was getting everything lined up correctly, especially the text and images. I also had a really difficult time with the borders and spacing. The bottom teal section was probably the most frustrating part because I could not figure out how to edit it and make it look like the original. I still haven't completely figured it out. What I did experience is that there is a lot of copy and pasting, especially with the different texts and fonts in CSS. This assignment helped me understand CSS better, especially how margins, padding, borders, and positioning can change the way a page looks. I learned that even small changes can affect the whole layout. If I had more time, I would keep experimenting with the teal section and work on making the spacing and alignment more accurate.
