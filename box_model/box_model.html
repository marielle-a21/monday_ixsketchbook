Working on this assignment helped me better understand how HTML elements take up space on a webpage. One thing that helped me understand the difference between margin and padding was changing the values and watching the space around the elements change in the browser. I noticed that padding creates space inside an element, while margin creates space outside of it. Adding borders and backgrounds also made the different parts of the box model much easier to see. I struggled when I was trying to add the Box Model folder to my navigation system. I kept having trouble because I forgot that the HTML file inside the folder had a different name. Once I realized that my file path needed to match the actual name of the HTML file, I was able to fix the link. This taught me to pay closer attention to how my folders and files are organized. Using the browser Inspector was very helpful because I could experiment with different CSS values without changing my actual code. It helped me understand which styles were affecting each element. Moving and renaming the folder into my Interactive Sketchbook also reminded me how important file paths are. This assignment gave me a better understanding of how HTML and CSS work together to control the layout and appearance of a webpage.
