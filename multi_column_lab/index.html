I learned how to use flexbox to organize the layout of a webpage. I decided to make the main part of the page the flex container because it included the headers, lyrics, and photo. I chose these because they were the elements I needed to organize into a column. The flex items are the paragraph elements containing the lyrics and the album information. Before I applied display: flex, the lyrics and album information were stacked on top of each other. After applying display: flex, they were arranged into columns, creating a more organized two-column layout. Changing the widths helped control how much space each column took up, while adjusting the margins and padding helped create spacing between the elements and made the page look cleaner. One challenge I had to troubleshoot was getting the font to work correctly. I was unsure how to connect the font file, so I experimented with using ../ in the file path to navigate out of one folder and into another where the font was stored. This helped me better understand how file paths work. I also realized this was something we learned in past html and css lessons that I could apply to this project.
